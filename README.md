# Java API Testing Demo

This repository contains a Java-based API testing practice project focused on REST API scenarios, OAuth authentication flow, POJO classes and response validation.

The goal of this project is to demonstrate practical knowledge of API testing using Java, including request modelling, authentication handling, data mapping and basic test structure.

## Tech Stack

- Java
- Maven
- REST API Testing
- OAuth
- POJO Classes
- Git & GitHub

## What This Project Covers

- OAuth authentication flow
- E-commerce API testing scenarios
- Request and response validation
- POJO classes with getters and setters
- Basic API test organisation
- Java-based test automation practice

## How to Run

Clone the repository:

```bash
git clone https://github.com/Willowviu/java-api-testing-demo.git
```

Move into the project folder:

```bash
cd java-api-testing-demo
```

Install dependencies:

```bash
mvn clean install
```

Run the tests:

```bash
mvn test
```
